**方法檢核結論**
1. 每個 G 都對應到至少一條 R（G2.*、G3.5.*、G6.6.*、G3.6.b、G6.4.b 全數涵蓋）。
2. 第一版 48 條中有 19 條需要拆分（約 40%），而且是經過一次獨立稽核才找出大半：後續各章每章都要排一次獨立稽核，不能只靠起草者自查。
