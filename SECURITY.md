# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.x.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

The security of **AI HUD Monitor** is taken seriously. Because this application interacts with local authentication tokens (`~/.claude/`, `~/.codex/`, `~/.gemini/`), protecting credentials from unauthorized exfiltration is paramount.

### Guidelines:
* **DO NOT report security vulnerabilities through public GitHub issues.**
* Please report any security vulnerabilities privately via GitHub Security Advisories, or contact the project maintainer directly.
* Include detailed steps to reproduce the vulnerability, along with your platform details (Windows/macOS version).
* Maintainers will acknowledge your report within 48 hours and coordinate a patch and CVE disclosure if applicable.
