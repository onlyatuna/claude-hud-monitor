# 規格：側邊欄模式 v2（可縮放、四邊磁吸的迷你雙長條小條）

狀態：v2 設計已確認（2026-10-16 使用者回饋後重做）；實作進行中。實機行為待使用者在 Windows 上確認。

## 1. 目標

HUD 的第三種 UI 模式 `sidebar`：像 IntelliJ 工具視窗列的小條，**縮小**、**可縮放**、**可自由拖曳並磁吸到螢幕任一邊**，
內容是**迷你雙長條磚**（5 小時、一週各一條，旁邊直接寫已用％）。UX 判斷：小尺寸下圓餅＋外環＋虛線＋斜紋太花、角度比長度難讀，且使用者不是 24 小時均勻使用，平均進度線無意義。
沿用 HUD 的懸浮特性：置頂、半透明、可滑鼠穿透、可蓋住其他視窗；**不**向系統保留空間（不用 AppBar）。`cards`、`table` 兩種模式保留。

## 2. 已定決策（使用者確認）

| 項目 | 決策 |
|---|---|
| 停靠 | 置頂懸浮視窗，不用 AppBar |
| 大小 | **縮放比例**：預設縮小到接近 IntelliJ 右側工具列的寬度（基準寬 64 邏輯像素）；Ctrl＋滑鼠滾輪即時縮放，範圍 60%～200%，記住設定 |
| 位置 | **自由拖曳＋靠近就吸附**：可放在螢幕任何位置；拖到離任一邊 24 px 內放開就吸附貼齊。貼左／右邊＝直條，貼上／下邊＝橫條（磚排成一列） |
| 內容 | 每個服務一塊**迷你雙長條磚**（見 §3），數值一律是**已用％**；停留／點擊彈出完整卡片（飛出面板） |
| AGY | 磚＝Gemini（5H、7D 兩條）；磚上兩顆**小點**代表 C/G 與 Argon 的剩餘色階（綠／黃／紅，灰＝無資料）；飛出面板有完整五條 |
| 形態 | 細條與固定窄欄（完整卡片）兩種都保留，可切換 |
| 選單 | 精簡成三組＋少數頂層項目（見 §6） |

## 3. 細條（strip）

- 基準尺寸（縮放 100%）：每個服務一塊 **64×64** 邏輯像素的磚，由上到下：服務簡稱（服務色、粗體；AGY 在右側有兩顆小點；STALE 時右上角琥珀點）、
  `5H` 列（標籤＋已用％）加 4 px 長條、`7D` 列加 4 px 長條。長條填色與數字用同一個色階（`scale_level`，雙色配色時用 duo 色）。
- 不畫平均進度虛線、斜紋與倒數；重設倒數只放在 tooltip 與飛出面板。
- 縮放 < 0.8 時隱藏 `5H`／`7D` 標籤文字，只留數字與長條；字級最小 8 px。
- 頂端一個小按鈕（約 64×22）：展開成窄欄／回細條；設定入口改為**右鍵整條**（不再放獨立設定按鈕）。
- 顏色：沿用表格模式的色階（`scale_level`，`THEMES[...]['scale']`）；亮／暗隨 `appearance`。
- AGY 的兩顆小點：位於磚的名稱列右側，各約 6 px，顏色依 `C/G 7D`、`ARGON 7D` 兩列的已用％取色階；`None` 用灰。tooltip 列出完整五條的已用％。
- 錯誤：長條只畫底軌、數字顯示 `OFF`；STALE：琥珀色小標記。
- 橫條（貼上／下邊）：同樣的按鈕排成一列（約 3×64 寬 × 68 高）。
- 飛出面板：停留 300 ms 或點擊 → 在按鈕**遠離螢幕邊緣的一側**彈出（貼右邊→往左、貼左邊→往右、貼上邊→往下、貼下邊→往上、未貼邊→往左），寬 260 px，內容是該服務完整卡片；
  離開 600 ms 或 Esc 收起；點擊釘住。不得超出所在螢幕。

## 4. 固定窄欄（panel）

三張卡片：直條時直式堆疊（寬 220 px × 縮放），橫條時三張並排。縮放比例同樣作用（字級、間距等比）。無飛出面板。

## 5. 視窗行為

- 視窗：無邊框、置頂、工具視窗、不搶焦點；沿用 `opacity`、`click_through`、`always_on_top`、`locked` 設定
- 拖曳：整條可拖（`locked` 時不可拖）；拖曳中可自由移動，放開時用 `snap_rect` 判斷是否吸附（24 px）
- 吸附：靠左／右 → 直條、貼齊該邊；靠上／下 → 橫條、貼齊該邊；角落時以先靠近的那一邊為準；離開所有邊 → 保持目前方向（不改朝向）
- 縮放：Ctrl＋滾輪（滑鼠在條上時）；縮放後維持吸附邊貼齊、以條的中心為基準位置不亂跳；範圍 60%～200%，步進 10%
- 設定鍵：`sidebar_scale`（預設 1.0）、`sidebar_edge`（`"left"|"right"|"top"|"bottom"|"none"`，預設 `"right"`）、`sidebar_pos`（吸附邊上的位置偏移，或未吸附時的左上角座標）、`sidebar_state`（`strip`|`panel`）
- 預設位置：右邊、靠下（沿用右下角、離底邊 12 px）
- 解析度／螢幕插拔：重新貼齊；位置落在螢幕外要拉回
- 多螢幕：貼目前所在螢幕的邊；不提供選螢幕設定

## 6. 選單精簡

右鍵（任何模式）與系統匣共用同一份選單結構，頂層只有：

1. 🔄 立即重新整理
2. **介面 ▸**：風格（卡片／表格／側邊欄）；卡片模式才出現「佈局」；側邊欄模式才出現「形態（細條／窄欄）」與「大小（縮小／預設／放大，或提示 Ctrl+滾輪）」
3. **外觀 ▸**：淺色／深色／跟隨系統、配色（色階／雙色，表格與側邊欄用）、視窗透明度
4. **行為 ▸**：滑鼠穿透、永遠置頂、鎖定位置、開機自動啟動、更新頻率
5. **更多 ▸**：Claude 帳號、開啟記錄檔目錄、重設預設尺寸與位置、隱藏 HUD
6. ❌ 結束

不重複：同一個設定只出現一次；系統匣只放「顯示／隱藏、重新整理、介面風格、結束」。

## 8. 不在範圍

AppBar／保留空間、自動隱藏、多螢幕選擇、自訂服務順序、exe 內建的 agy statusLine 啟用流程。

## 9. 風險

- 高 DPI：縮放以邏輯像素為準，Qt 會處理裝置像素；實機請確認 125%／150% 縮放下磚與長條清楚
- 離屏截圖無法證明實機的吸附、穿透與透明度，需使用者實機驗證
- 縮到 60% 時磚只有約 38 px 寬：隱藏標籤文字，只留數字與長條；完整資訊靠 tooltip

## 10. 使用後追加的需求（2026-10-17，已實作）

- 橫條（貼上／下邊）時，切換鈕改成右側的細長把手，不再佔左邊一整欄。
- 縮放：除了 Ctrl＋滾輪，也可拖拉四邊與四角（視窗邊緣 7 px 內），等比例縮放，對邊／對角固定。
- 飛出面板有圓角；停留在另一個服務上時直接切換內容，不再跳出原生 tooltip（飛出面板已顯示詳細資料）。
- AGY 主要兩條可選（`agy_primary`，預設 C/G 5H＋ARGON 7D）：從「介面 → AGY 主要兩條」選；磚上顯示選中的兩條，其餘三條變成名稱列右側的小點，卡片與表格的主要兩個窗口也一併跟著換。
- 服務順序可自訂（`provider_order`）：細條上按住磚 350 ms 再拖曳即可換位；順序同時套用到卡片、表格與窄欄。快速拖曳仍是移動整條。
- 釘住邏輯：點一個服務會釘住它的詳細頁；滑到另一個服務會直接切換且保持釘住；再點「已釘住的那個」才取消。（修正：以前切換後再點會把頁面關掉）
- 磁吸靠角：直條拖到右下角（或任一角）仍是直條並貼齊角落，橫條同理；不再因為靠近下邊就轉成橫條。貼角時設定記為 `sidebar_offset = "end"`（貼到該邊的終點）。
- AGY 項目順序：在詳細頁面直接拖拉標題換順序（`agy_order`，前兩條為主要顯示）；選單只顯示目前順序與「還原預設順序」。
- 詳細頁的每一條（標題＋長條＋重設時間）是一個整塊格子：滑過會微微反灰、游標變手形，按住整塊拖曳即可換順序，放開前有提示線。Claude、Codex、AGY 都支援（`row_order`；AGY 仍用 `agy_order`）。表格模式的圓盤固定「內圈 5 小時、外環一週」，不套用自訂順序。
- 品牌色（`ui/brand.py`）：Claude 陶土橘（暗 #D97757／亮 #B4532F）、Antigravity Google 藍（暗 #8AB4F8／亮 #1967D2）、Codex OpenAI 綠（暗 #10A37F／亮 #0B7A5E）。只用在身分標示（名稱、磚左側細色條、焦點框、拖曳提示線、表格圖示與名稱）；長條與百分比一律維持綠／黃／紅狀態色。亮色變體加深到名稱對磚底色 ≥ 4.5:1（有測試）。
- 週額度（視窗 ≥ 1 天）的重設標示實際時間：`重設於: 週五 18:00 · 6天 5時 55分`；5 小時視窗只顯示倒數。
- 磚上長條與百分比一律同一個顏色（`_Button.row_color`）：色階色對磚底色對比不足（< 3:1）時，亮色主題調暗、暗色主題調亮，**只動明度、不換色相**，長條與數字共用調整後的顏色；不再有「數字退回黑色、長條仍是彩色」的不一致（雙色與色階兩種配色都適用）。
- 閒置淡化（`sidebar_idle_fade`，預設開）：側邊欄在沒有滑鼠停留、沒有開著詳細頁時，透明度降到你設定值的 60%；滑過恢復。穿透模式（無法 hover）與卡片、表格模式不淡化。選單「行為 → 閒置時淡化」可關。
- 接近上限標記：磚上任一條已用 ≥ 90% 時，名稱列右側出現紅色警示三角（內有「!」，不單靠顏色），tooltip 多一行「接近上限」；離線的磚不標。
- 重設提示：某個視窗重設（重設時間往後跳超過 10 分鐘且用量下降）時，該磚以服務色微亮約 1.8 秒（系統關閉動畫時靜態顯示後熄滅）。
- 選單文字去掉 emoji，統一純文字，避免不同字型下圖示大小不一。
- 側邊欄一律用狀態色（綠→黃→橘→紅），不再跟隨表格模式的「雙色」配色設定（那個設定只影響表格；選單的「配色」只在表格模式出現）。原因：雙色模式下磚上只有藍紫，看不出快不快滿。
- 長條是「漸層量表」：固定的綠→黃→橘→紅漸層（色階分界 0／50／75／90%），只露出到目前用量的長度，所以長條前端的顏色永遠等於右側百分比的顏色（`_Button.ramp`），位置本身也傳達用量。漸層色與數字色都經過同一個可讀性調整（對磚底色 ≥ 3:1，只動明度）。
- 漸層量表統一到卡片與詳細頁（`ui/gauge.py`）：`GaugeBar` 取代 QProgressBar，與側邊欄磚共用同一組「綠→黃→橘→紅」色階與可讀性調整（對卡片／飛出面板底色 ≥ 3:1，只動明度）；百分比數字的顏色就是長條前端的顏色。卡片原本的「綠／藍／琥珀／紅」分段色（`get_progress_color`）不再用於卡片。表格模式的圓盤與雙色配色維持原樣。
